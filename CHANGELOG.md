# CHANGELOG

Todos los cambios notables del ERS de este proyecto se documentan en este archivo.

## [1.1.0] - 2026-07-22

### Added
- RF-16 (Could, Fase 2): asistente virtual con IA para preguntas frecuentes y agendamiento de citas (RFC-001)

### Changed
- RNF-02: disponibilidad actualizada de horario laboral (99% en 07h00–18h00, L–V) a 99% las 24 horas, los 7 días de la semana (RFC-002)
- Corregida colisión de ID RNF-06 -> RNF-08 en el Acta de Negociación N.°1 y en la matriz de trazabilidad; RNF-6 queda exclusivamente como el NFR de recuperación ante fallos (RFC-003)

## [1.0.0] - 2026-06-12

### Added
- Versión inicial del ERS (PE2 — elicitación y análisis): requisitos funcionales RF-01 a RF-15, no funcionales RNF-1 a RNF-6, modelo i* (SD/SR), casos de uso, user stories y misuse scenario.
